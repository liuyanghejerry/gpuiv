Add Vue 3 bindings for GPUI as `@gpuiv/vue`: a custom renderer that mounts Vue components on the native GPUI retained tree through the same mutation protocol as the React bindings, with GPU-backed testing (`createTestApp`), automation (`connectTest`), native motion support, and `@gpuix/native` renamed to `@gpuiv/native`.
